Before implementing a provider:

1. Check docs/feasibility/.
2. Check whether the provider source is verified.
3. Never invent a quota endpoint.
4. Never print/store secrets.
5. Prefer provider-supported local/API/OAuth sources.
6. Implement one working feature at a time.
7. Update docs after a provider discovery or architectural change.
8. Do not modify unrelated UI.
9. Run local validation before committing.
